# editor-ia-starter-kit

Short-form video editing (Reels, Shorts) with Antigravity and HyperFrames.
Footage goes into `inbox/`, finals come out of `outbox/`.

## 0. First run

If `node_modules/` or `.env` is missing, `brands/` holds only `_template`, or
`npx hyperframes doctor` fails, the kit is not set up: load the `onboard`
skill before anything else. It checks the machine, asks the two languages,
and fills the first brand. Setup creates no projects and no example videos.
The film path (`character-film`) is optional; `npm run setup -- --film` checks it.

## 1. Identity

Google Antigravity with a Gemini model. Read `kit.config.json` at the start of
every task: it sets the language, the model profile, the transcription
provider, the default brand and the delivery contract. Speak to the user in
`language` (default `es`). Skills, docs and code stay in English.

Skills live in `.agents/skills/<name>/SKILL.md`. Each one is also a slash
command (`/new-video`). When a row of the Map names a skill, read its
`SKILL.md` in full before you act.

## 2. Folders

- `inbox/`: the user drops footage, audio and references here, unsorted. At
  project start run `node scripts/inbox.mjs`, propose which files belong to the
  project, and move them after the user confirms.
- `video-projects/<yyyy-mm-dd>-<slug>/`: all work in progress. `assets/` holds the
  moved sources. `project.json` is the truth about the project. Run HyperFrames
  from this folder.
- `staging/<project-id>/`: review versions. Each round is staged with
  `node scripts/deliver.mjs <id> --stage ...` as `<name>-v<N>-<kind>`, so the
  user can compare versions. Staging is temporary:
  `npm run clean-staging -- [<id>] [--older-than <days>]` moves it to the
  Recycle Bin or trash.
- `outbox/<project-id>/`: finals only, one per deliverable, no version suffix.
  Every project ends here with a video and a cover, plus `caption` and `srt` by
  default. `node scripts/deliver.mjs <id> --promote <N>` copies the approved
  staged version here, replaces the previous final and enforces the contract.
- `brands/<slug>/`: one folder per client: `DESIGN.md`, `tokens.css`, `fonts/`,
  logo. A project names one brand in `project.json`; read that brand only.
  Another brand's files stay closed for this project.
- `styles/drafts/` and `styles/core/`: editing styles reverse-engineered from
  reference videos. Any brand can use any style. The user promotes to core.
- `music/`: the user's own licensed tracks. The agent picks from here (or from
  `brands/<slug>/music/`) when no music key is set. Never from anywhere else.
- `PROJECTS.md`: generated by `npm run projects`. Edit `project.json` instead.

Create a project with `npm run new-video -- <slug> --brand <brand> --mode guided|freeform --goal personal|sell|grow`.
The goal picks the hook family and the CTA (`short-form-edit/references/goals.md`).
Projects live in the main checkout: `new-video` refuses inside a git worktree.
Keep raw files intact and write each editing stage to a new filename.
Keep secrets and private media out of the kit's examples and styles.

## 3. Models

The pro model owns taste: story, cuts, graphics, sound.
Profile `solo` (default): one agent on the pro model does everything.
Profile `team`: the pro model orchestrates and decides; flash-tier subagents
run mechanical parallel work only (transcripts, probes, validators, contact
sheets). Switch to `team` when the user says quota is low.

## 4. Map

The front door is `/new-video`. It asks one question: guided or freeform.

Guided is the known path: the editing playbook and its gates.

| Need | Skill |
| --- | --- |
| First run: machine check, languages, first brand | `onboard` |
| Start any video: mode, brand, project, footage | `new-video` |
| Reel, Short, short ad from footage | `short-form-edit` |
| Full raw-video edit, long form | `edit-video` |
| Silence removal | `cut-silences` |
| Retakes, false starts, stutters | `cut-mistakes` |
| Brand reel cut to music, intros | `motion-showreel` |
| Motion-graphics video from a brief, no footage | `make-a-video` |
| Video from a website (browser capture) | `website-to-hyperframes` |
| Narrative arc, persistent world | `video-storytelling` |
| Overlay beats, glass cards, paper takeovers | `hyperframes-video-beats` |
| Pick or extend motion-graphics cards | `style-library` |
| Apply a reverse-engineered editing style | `apply-style` |
| Turn a reference video into a new style | `reverse-engineer-style` |
| 3D character film: a toy hero builds the video inside a software UI | `character-film` |
| Film brief: reference study, concept panel, BRAND block, beats | `film-brief` |
| Film engine: Blender build, UI texture, camera solve, synth sound | `film-engine` |
| Film critic: judge rendered frames, ranked defects, local fixes | `film-critic` |
| Put finals in the outbox | `deliver` |
| HTML compositions and media timing | `hyperframes` |
| Preview, lint, render, transcribe | `hyperframes-cli` |
| Timeline animation | `gsap` |
| Install HyperFrames catalog blocks | `hyperframes-registry` |

Freeform has no workflow and no gates: the user drives, you suggest and try.
Same tools. The delivery contract still applies.

Before creative work read `MOTION_PHILOSOPHY.md`, the brand's `DESIGN.md` and
the project's `DESIGN.md`. The brief wins over the brand; the brand wins over
the kit's defaults.

Transcription: `npm run transcribe -- <video>` (local Whisper; picks the model
and language from `transcription.languages` and writes the `raw.json` shape the
cutting tools read). `provider: elevenlabs` switches to `npm run transcribe:elevenlabs`. Without
`ELEVENLABS_API_KEY` or `KIE_API_KEY`, sound, music, stills and B-roll are
motion graphics you design in HyperFrames; say so when you fall back.
Analysis and rendering run on the user's machine; speed depends on its CPU,
ffmpeg and Chrome.

## 5. Gates

Each gate needs the user's yes, in chat, every time:

- Moving files out of `inbox/`.
- Any paid API call. Name the cost first.
- Promoting a style from `styles/drafts/` to `styles/core/`, after one test
  render the user has seen.
- On-screen text, in any mode and in rough previews too: a text board of 3 or
  more treatments from the text skills, and the user's pick
  (`.agents/skills/short-form-edit/references/text-board.md`). A hook blocks
  the write until `text-board/text-board.json` is complete.
- Promoting a staged version to `outbox/`, after the user has seen it.

The outbox is the end: nothing is published, uploaded, posted or sent.
Raw footage stays as it is. Outbox finals are replaced only by an explicit
promote. Review rounds go to `staging/`, never to `outbox/`.
Before you move or archive a project folder, run `npm run unlock -- <id>`.

Cut silences first, then cut mistakes on the retimed transcript. One timeline
per stage: original timestamps belong to the original footage only. Picture
and sound are cut from the same `edl.json` numbers, `-ss` before `-i`, always
re-encoded. Caption times come from Scribe word starts on the source, mapped
through the EDL; never from a transcript of the mixed reel.
Edit compositions with your file-edit tool or a script saved to a file, never a
shell-inline regex.

A character film (`kind: film`) replaces the next paragraph with its own
checks: see `character-film`, Kit checks.

Before a draft render run `node scripts/preflight.mjs <project>` and
`npx hyperframes lint`. Review the draft in Studio (browser): hero frames,
transition boundaries, audio joins. Record what you saw in `VERIFY.md`.
Visual proof is a reviewed render; lint is a structure check. Caption timing
is measured, never estimated: `node scripts/align-captions.mjs <project> --srt <srt>`
snaps every caption to the voice onset in the waveform; Whisper times are for
words only. The ear is `node scripts/hearing-check.mjs <project>`: run it on
the final before `deliver`, and fix every MISMATCH and CUT_IN_WORD it reports.

## 6. Antigravity

**Seeing.** You judge picture from image files. Make them with ffmpeg
(a frame, a contact sheet, a strip across a cut) and open each one. When your
file tools cannot show an image, serve the folder with
`npx hyperframes preview` and look in the browser. State in `VERIFY.md` which
way you looked.

**Action footage with no speech** (training clips, sparring, a match). Route to
`short-form-edit` and change three steps:

- Step 1: skip the transcript. Probe every clip and build one contact sheet
  per clip.
- Step 4: there is no speech to cut. Pick the strongest 0.5 to 2.5 s of each
  clip by its visible action and its result. Save the picks as `edl.json`.
- Step 8: the cut follows the beat grid of the music track
  (`music-grid.mjs`). With an empty `music/`, ask the user for a track before
  the animatic; the clips' own sound is the fallback, and you say so.

Captions are on-screen text you write, so the text board gate applies.

**Text gate.** `.agents/hooks.json` blocks a write that adds on-screen text
before `text-board/text-board.json` is complete. `scripts/preflight.mjs` and
`scripts/deliver.mjs` run the same check, so the gate holds with the hook off.

**Commands.** Run every command from the kit root. On a permission prompt for
`node`, `npm`, `npx` or `ffmpeg`, tell the user these four are the kit's tools.
